Étape 6 : Surveillance des ports d’un serveur

Objectif : Créer un script Python qui vérifie si certains ports sont ouverts sur un serveur donné. Cela permet de s'assurer que les services réseau fonctionnent correctement (ex: HTTP sur le port 80, SSH sur le port 22, etc.).

import socket

 

# Demander l'adresse IP du serveur

ip = input("Entrez l'adresse IP du serveur : ")

 

# Liste des ports à vérifier (HTTP, SSH, DNS, FTP, etc.) ports = [80, 22, 53, 21]

 

# Fonction pour vérifier si un port est ouvert def check_port(ip, port):     sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)     sock.settimeout(1)  # Timeout d'une seconde     result = sock.connect_ex((ip, port))     sock.close()

         if result == 0:         return True     else:         return False

 

# Boucle sur les ports à vérifier for port in ports:     if check_port(ip, port):         print(f"Le port {port} est ouvert sur l'hôte {ip}.")     else:

        print(f"Le port {port} est fermé sur l'hôte {ip}.")

 

Explication :

•       La fonction socket.connect_ex() tente de se connecter à un port spécifique d'une adresse IP. Si elle retourne 0, cela signifie que le port est ouvert.

•       Ce script est utile pour vérifier si des services critiques fonctionnent sur un serveur.

Étape 8 : Envoi de requêtes HTTP avec la bibliothèque requests

Objectif : Vérifier la réponse d'un serveur web en envoyant des requêtes HTTP et en inspectant le code de réponse (200 OK, 404 Not Found, etc.).

Pré-requis :

Installez la bibliothèque requests avec :

pip install requests

 

 

Code Python :

import requests

 

# Demander l'URL du serveur web

url = input("Entrez l'URL du serveur (ex: http://example.com) : ")  

# Essayer d'envoyer une requête HTTP GET try:

    response = requests.get(url)

    

    # Vérifier le statut de la réponse     if response.status_code == 200:

        print(f"Le serveur est accessible. Code de statut : {response.status_code}")     elif response.status_code == 404:         print(f"Le serveur est inaccessible (Page non trouvée). Code de statut :

{response.status_code}")     else:         print(f"Le serveur a répondu avec le code de statut : {response.status_code}") except requests.ConnectionError:     print("Erreur de connexion au serveur.")  

Explication :

•       requests.get() envoie une requête HTTP GET à l'URL spécifiée et vérifie le code de statut de la réponse.

•       Ce script est utile pour tester la disponibilité d’un serveur web ou la réponse d’une API. Étape 9 : Génération d'un rapport de statut réseau

Objectif : Créer un script qui génère un rapport complet de la connectivité réseau, en effectuant des pings, des vérifications de ports, et des requêtes HTTP. Ce rapport sera ensuite enregistré dans un fichier texte.

Code Python :

import os import socket import requests

 

# Liste d'adresses IP à pinger ip_list = ["192.168.1.1", "8.8.8.8"]

 

# Liste des ports à vérifier ports = [80, 22, 443]

 

# URL à tester

url = "http://example.com"

 

# Fichier de rapport

rapport_file = "rapport_reseau.txt"

 

# Fonction pour vérifier les pings def ping_hosts(ip_list):

    result = []     for ip in ip_list:         response = os.system(f"ping -c 1 {ip}")         if response == 0:             result.append(f"L’hôte {ip} est Accessible.")         else:             result.append(f"L’hôte {ip} est Inaccessible.")     return result

 

# Fonction pour vérifier les ports def check_ports(ip, ports):     result = []     for port in ports:         sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)         sock.settimeout(1)

        result_code = sock.connect_ex((ip, port))         sock.close()         if result_code == 0:             result.append(f"Le port {port} est ouvert sur l'hôte {ip}.")         else:

            result.append(f"Le port {port} est fermé sur l'hôte {ip}.")     return result

 

# Fonction pour vérifier l'URL def check_url(url):     try:         response = requests.get(url)

        return f"L'URL {url} a répondu avec le code {response.status_code}."     except requests.ConnectionError:         return f"L'URL {url} est inaccessible."

 

# Générer le rapport with open(rapport_file, "w") as f:

    f.write("=== Rapport de Statut Réseau ===\n")

    

    # Vérification des pings

    f.write("\n--- Résultats des Pings ---\n")     ping_results = ping_hosts(ip_list)     for line in ping_results:         f.write(line + "\n")

    

    # Vérification des ports

    f.write("\n--- Vérification des Ports ---\n")     for ip in ip_list:         port_results = check_ports(ip, ports)         for line in port_results:

            f.write(line + "\n")

    

    # Vérification de l'URL

    f.write("\n--- Vérification de l'URL ---\n")     url_result = check_url(url)

    f.write(url_result + "\n")  

print(f"Le rapport a été généré dans le fichier {rapport_file}.")  

Explication :

•       Ce script combine plusieurs tâches (ping, vérification de ports, requêtes HTTP) et génère un rapport dans un fichier texte.

•       Il peut être utilisé pour monitorer rapidement l'état de connectivité d'un réseau ou d'un serveur.
